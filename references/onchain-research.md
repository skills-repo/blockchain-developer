# 链上研究方法论 Playbook

> 研究框架 > 小道消息。本 playbook 给出对区块链项目做结构化研究的可复用流程，从 tokenomics 到链上指标到竞争格局，产出可操作报告。

## 研究流水线（5 阶段）

```
1. 定位      → 项目做什么、解决什么问题、在哪个赛道
2. Tokenomics → 供应/分配/解锁/价值捕获（见 defi-tokenomics.md）
3. 链上验证  → 用数据验证叙事：活跃地址、TVL、手续费、留存
4. 竞争格局  → 同赛道对手、差异化、护城河
5. 风险论题  → bull case / bear case + 关键假设
```

## 链上指标字典（及解读陷阱）

| 指标 | 含义 | 常见误读 |
|------|------|----------|
| 活跃地址 | 每日交互地址数 | 刷量可虚高，需看留存 |
| TVL | 锁仓总值 | 高 TVL ≠ 安全，看来源稳定性 |
| 手续费收入 | 协议真实需求 | 补贴期会失真 |
| 净流入/流出 | 资金方向 | 滞后指标，不预测 |
| 持币集中度 | 顶部地址占比 | 交易所冷热钱包需剔除 |

**验证叙事原则**：任何"增长"叙事都必须有至少一项链上指标佐证；纯白皮书叙事不计入结论。

## 竞争格局框架

- **赛道容量**：TAM 与当前渗透率。
- **差异化**：技术 / 代币模型 / 生态壁垒。
- **护城河**：网络效应、流动性深度、开发者粘性、监管牌照。
- **替代风险**：更便宜/更快的对手是否可平替。

## 风险论题模板

- **Bull case**：哪些条件成立时价值重估（列可观测信号）。
- **Bear case**：哪些条件触发下行（解锁、监管、对手）。
- **关键假设**：结论依赖的最脆弱前提，一旦破裂结论失效。

## 输出

一份结构化研究报告：一句话结论 + 链上证据表 + 竞争对比 + 风险论题 + 数据快照时间。明确标注"分析不代表投资建议"。

## 边界

- 不做价格预测；只做基于事实的结构化判断。
- 数据可能有延迟/刷量，所有量化结论附快照时间。
