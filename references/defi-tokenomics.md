# DeFi 收益与 Tokenomics 分析 Playbook

> 收益来自理解，不来自运气。本 playbook 给出结构化框架：先判断收益来源，再评估可持续性，最后量化风险。

## 决策树：一个 yield 机会该不该碰

```
看到某协议 APY 很高
  ├─ 收益来源清晰吗？(流动性激励 / 借贷利差 / 手续费 / 杠杆)
  │    ├─ 否 → 视为庞氏结构，回避
  │    └─ 是 → 进入可持续性评估
  ├─ 排放是否在衰减？(是) → 真实收益率 = 剔除代币排放后的净收益
  └─ 有无未披露解锁 / 团队 Allocation？(是) → 高风险，折价计入
```

## 收益来源四象限

| 来源 | 可持续性 | 风险点 |
|------|----------|--------|
| 交易手续费 | 高（真实使用） | TVL 波动、竞争 |
| 借贷利差 | 中高 | 坏账、清算连锁 |
| 流动性激励（代币排放） | 低（通胀） | 排放结束即崩 |
| 杠杆循环（loop） | 中 | 清算螺旋、脱锚 |

**真实收益率（Real Yield）** = 协议收入中分配给 LP/质押者的部分（剔除代币通胀）。永远用真实收益率而非名义 APY 做横向比较。

## Tokenomics 评估维度

1. **供应结构**：总量、流通量、通胀率、销毁机制。
2. **分配与解锁**：团队 / 投资人的 cliff 与线性解锁时间表；关注未来 90 天解锁 cliff。
3. **价值捕获**：代币是否捕获协议收入（回购销毁 / 分红 / 治理溢价）。
4. **集中度**：前 10 地址持币占比、LP 集中度。
5. **排放曲线**：排放速率是否衰减、是否有上限。

## 量化速算（确定性 — 用脚本，不要手算）

四个口径已固化在 `scripts/defi_yield_calc.py`，**不要每次重写公式或凭记忆报数**：

```bash
# APY 换算：APY = (1 + APR/n)^n − 1（n 为每年复利频次，默认 365）
python3 scripts/defi_yield_calc.py apy --apr 0.45

# 真实收益率 =（协议收入 − 代币排放价值）/ 质押 TVL；净收入 <= 0 判庞氏
python3 scripts/defi_yield_calc.py real-yield --revenue 1200000 --emissions 900000 --staked-tvl 25000000

# 解锁冲击比 = 解锁额 / 日均成交量；> 0.3 显著抛压
python3 scripts/defi_yield_calc.py unlock --tokens 5000000 --price 1.2 --daily-volume 8000000

# TVL/MCap 比；< 0.1 估值相对锁仓过高
python3 scripts/defi_yield_calc.py tvl-mcap --tvl 40000000 --mcap 500000000

# 一次跑完四项并汇总风险信号（--json 可写入报告；命中风险时退出码 1）
python3 scripts/defi_yield_calc.py screen --apr 0.45 --revenue 1200000 --emissions 900000 \
    --staked-tvl 25000000 --tokens 5000000 --price 1.2 --daily-volume 8000000 \
    --tvl 40000000 --mcap 500000000 --json
```

**阈值单一来源**：`> 0.3` 抛压、`< 0.1` 脆弱、真实收益率 `<= 0` 庞氏，三者同时写在脚本常量与本文；
改阈值必须两处同步，否则报告口径与脚本判定会打架。

## 常见坑（踩过的）

- **拿名义 APY 横向比较**：不同协议复利频次不同，必须先统一换算成 APY 再比，且换算完仍要看真实收益率。
- **排放价值按当前币价算**：排放本身会压价，高排放协议的"年化排放 USD"是乐观估计，结论要留折价。
- **质押 TVL 与协议 TVL 混用**：真实收益率的分母是**能分到收益的那部分**锁仓，不是全协议 TVL，混用会显著高估。
- **只看解锁总量不看流动性**：同样 500 万枚解锁，日均成交 8000 万和 800 万是两种性质，务必用冲击比而非绝对量。
- **`--json` 位置**：脚本允许 `--json` 放在子命令前后任一位置，但混在数值参数中间会被 argparse 归错，建议放末尾。
- **忽略退出码**：`screen` 命中风险阈值返回 1，在 CI/批处理里用 `&&` 串联会被当失败中断，需显式判断。

## 分析前检查清单

- [ ] 收益来源已归入四象限之一（手续费 / 借贷利差 / 排放 / 杠杆），来源不明即判庞氏并回避
- [ ] 已用 `defi_yield_calc.py real-yield` 算出真实收益率，而非直接引用页面 APY
- [ ] 排放依赖度已核对（排放 / 收入），高于 100% 明确标注
- [ ] 未来 90 天解锁 cliff 已查，并用 `unlock` 子命令算过冲击比
- [ ] TVL/MCap 已算，脆弱（< 0.1）情形已在结论中提示
- [ ] 前 10 地址持币占比已剔除交易所冷热钱包
- [ ] 所有量化结论已标注数据快照时间
- [ ] 结论中已声明"不构成投资建议"

## 输出模板

对每个 DeFi 标的产出一段话结论：收益来源 + 真实收益率 + 解锁风险 + 打分（1–5）。不替用户下注。

## 边界

- 不构成投资建议；只做框架化分析。
- 链上数据会滞后，结论需标注数据快照时间。
