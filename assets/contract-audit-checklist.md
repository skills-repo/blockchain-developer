# 智能合约安全审计检查清单

> 部署前逐项核对。全部勾选不代表绝对安全，仅构成自检基线；高价值合约仍需第三方审计。

## 访问控制
- [ ] 所有特权函数（mint / pause / upgrade / withdraw / setX）有鉴权
- [ ] 默认拒绝：未显式授权的路径不可执行敏感操作
- [ ] 权限可撤销 / 多签治理，无私钥单点失控

## 算术与溢出
- [ ] 编译器 ≥ 0.8.0（默认溢出检查）
- [ ] 所有 `unchecked` 块都有注释解释并已手工保证边界

## 外部调用
- [ ] 外部调用前已完成状态更新（Checks-Effects-Interactions）
- [ ] 已加 `nonReentrant` 守卫于提现/转移路径
- [ ] 低级调用（`.call` 等）返回值已显式检查
- [ ] 采用拉取模式（pull over push）处理退款

## 鉴权与随机
- [ ] 无 `tx.origin` 鉴权（一律 `msg.sender`）
- [ ] 无 `block.timestamp` / `now` 用于强随机
- [ ] 随机数走 VRF 或提交-揭示方案

## 依赖与版本
- [ ] pragma 锁定精确版本（无 `^` 浮动）
- [ ] 无已废弃函数（sha3 / callcode / suicide / throw）
- [ ] 第三方依赖（OpenZeppelin 等）版本固定且已审计

## 经济与治理
- [ ] 代币排放 / 解锁时间表已披露并计入抛压评估
- [ ] 预言机抗操纵（TWAP / 多源）
- [ ] 升级路径有 timelock / 多签，非即时

## 测试与验证
- [ ] 关键路径有单元测试 + 至少一条 invariant / fuzz 测试
- [ ] 清算、升级、紧急暂停已演练
- [ ] 已做对手视角模拟（攻击者重放）

## 上线前
- [ ] 至少一轮第三方审计或等价评审
- [ ] 已部署到测试网完整跑通
- [ ] 紧急响应预案（暂停 / 升级 / 沟通）就绪
