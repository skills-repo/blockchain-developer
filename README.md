# 区块链开发者技能库

> AI Agent Skills for Blockchain Developers —— 合约安全、DeFi 收益、市场分析、项目研究

## 定位

为独立区块链开发者和加密投资者提供一套 Web3 全流程 AI 技能，覆盖智能合约安全、DeFi 策略、市场情报和项目研究。

## 核心理念

> 区块链开发者的工具箱里最缺的不是代码，是安全意识和研究能力。本技能库教你：先审计再部署，先分析再投资，先研究再决策。

- **合约安全不是可选** — 部署前必须经过系统的安全检查
- **DeFi 收益来自理解，不来自运气** — 知道钱从哪来，才能判断风险
- **市场信号比价格预测可靠** — 追踪趋势、情绪和聪明钱，不做价格算命
- **研究框架 > 小道消息** — 结构化的分析比电报群喊单靠谱
